The qrkude logo is a mark and a wordmark. The mark, **chain eyes**, is two QR
code eyes (the square patterns in the corners of every QR code) linked like a
chain. The wordmark is "qrkude" in lowercase.

## Files

| File | What it is |
|---|---|
| `qrkude-logo.svg`, `qrkude-logo.png` | The logo, for light backgrounds (PNG: 1600 px wide) |
| `qrkude-logo-dark.svg`, `qrkude-logo-dark.png` | The logo, for dark backgrounds |
| `qrkude-mark.svg`, `qrkude-mark.png` | The mark alone, for light backgrounds (PNG: 512 px) |
| `qrkude-mark-dark.svg`, `qrkude-mark-dark.png` | The mark alone, for dark backgrounds |
| `qrkude-icon.svg`, `qrkude-icon.png` | The mark on an indigo square: avatar or app icon (PNG: 512 px) |

Prefer the SVG files: they stay sharp at any size, and the PNG files have a
transparent background. The colors are ink `#151922` and indigo `#3451d1`, or
`#e9ecf2` and `#8197ff` in the dark versions.

To keep the logo recognizable, leave some empty space around it, use the dark
versions on dark backgrounds, and don't recolor, stretch or rotate it.
